# Trademark and naming policy

The MIT License in this repository covers the **code**. It does not grant any
right to use the StarMap name, logo, or other product branding. This file
explains what you may and may not do with them.

## Background

The name "StarMap" originates from the upstream project by
[Aisland-SJL](https://github.com/Aisland-SJL/StarMap), from which this
repository forked. This policy governs how the maintainers of this repository
use and permit the name for **their** product line (StarMap Core, StarMap Plus,
StarMap Cloud). It makes no claim against, and places no restriction on, the
upstream project or its author.

The product name may change in the future. If it does, this file and the
READMEs will be updated; the code license will not.

## You may

- Refer to this project by name, for example "built on StarMap" or
  "a fork of StarMap", including in blog posts, talks, and documentation.
- Distribute unmodified builds of this repository under the StarMap name.
- Keep the name in a private fork or in an internal deployment that is not
  offered to others as a product.

## Please do not

- Offer a modified version, a hosted version, or a competing product to others
  under the name "StarMap" or a confusingly similar name (for example
  "StarMap Pro", "StarMapp", "Star Map Cloud").
- Use the StarMap logo or brand assets in a way that suggests your product,
  fork, or service is official, endorsed, or maintained by this project.
- Register domain names, app-store listings, or social accounts containing
  "StarMap" that could be mistaken for this project.

If you distribute a modified version as a product, pick your own name and state
that it is "based on StarMap" instead.
